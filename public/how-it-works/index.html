HOW IT WORKS // SI-01

PUNCH. SYNC. REPEAT.

The core loop is intentionally easy to understand before the deeper systems appear.

1. Punch

Click, tap, or press Space on the machine. A manual punch immediately increases your local run and gives tactile feedback.

2. Global impact

The public counter represents shared damage. The browser queues impacts and sends bounded batches to the server instead of making a database write for every click.

3. Spend tokens

Tokens are used by automation. They regenerate up to a cap, while direct manual punches remain free.

4. Build automation

As your run grows, you unlock Micro, Fast and Slop automation. Automation trades tokens for additional impacts and introduces different risk/reward behavior.

5. Go deeper

Progression, builds, daily modifiers, world events, challenges, achievements, seasons and endgame systems become relevant after the basic punch loop is already clear.

6. Play offline-ish

The client keeps the current run locally and queues global impacts when the network is unavailable. Reconnection and periodic reconciliation flush pending batches.

Important: the global counter is a public game statistic, not a scientific measurement. The game treats cheating as an on-brand possibility; backend protections focus on limiting resource abuse and keeping the service usable.
