FREQUENTLY ASKED QUESTIONS

Everything you actually need to know before punching the machine.

What is FUCKYOUAI.SI?

It is a free browser rage clicker where players punch an AI/SI machine and contribute to a shared global impact counter.

Is it free?

Yes. The game is designed to be played for free in a modern web browser.

What does AI → SI mean?

It is the fictional joke premise: AI becomes SI, nobody asked, and the correct response is to punch the machine.

Do I need an account?

No account is required for the core game loop. It is designed around anonymous browser play.

Does every click write to the database?

No. The client queues impacts and synchronizes them in bounded batches so the global counter does not require one database write per click.

What are tokens?

Tokens are a game resource used by automation. They regenerate up to a cap; manual punches remain free.

Is the global number a real-world statistic?

No. It is a shared game statistic inside the fiction of FUCKYOUAI.SI.

What is Singularity?

Singularity is the late-game progression track. It is intentionally discovered later instead of being presented as part of the first-session tutorial.
